# Rime Nasser-Eddine — Portfolio

Welcome to my portfolio. This site showcases selected projects, my process, and the design and interaction decisions that shape how I present my work.

## Live site
- View the live portfolio at: https://rime-nasser-eddine.netlify.app/

## What this portfolio contains
- Navbar: site navigation and quick access to sections.
- Hero: name, role, and primary calls to action.
- About: brief biography, key stats, and skills.
- How I Work: an outline of my process and working approach.
- Case Studies: curated project cards that describe goals, outcomes, and my role.
- Footer: contact links and relevant resources.

## Design rationale

### Colors
- The warm peach and cream base feels inviting, calm, and professional, which reflects my personality.
- I wanted the page to feel welcoming because I consider myself kind and open; the palette supports that tone.
- A coral accent provides visual energy for links, buttons, and lines without overwhelming the page.
- A softer green accent adds balance and a secondary tone for subtle emphasis.
- The site is dark-mode friendly: when a visitor's browser is set to Dark mode, colors adapt so backgrounds turn darker and accents are modified to remain legible and harmonious.

### Typography
- I chose lighter, calmer fonts to avoid an aggressive, technical feel.
- Fonts used:
	- `--font-display`: Quicksand for headings and display text, approachable and friendly.
	- `--font-sans`: Nunito for body copy for readability and warmth.
	- `--font-mono`: Fira Code for monospace for code snippets and tech-oriented labels.

### Screen layout and structure
- The site is section-based and responsive, using a grid system for balanced layouts:
	- `Navbar` • `Hero` • `About` • `How I Work` • `Case Studies` • `Footer`
- The layout leverages responsive classes (container, row, col-lg-6, col-md-6, etc.) so content adapts across screen sizes.

### Design principles applied
- Scale: large hero headings and section titles create strong entry points, and smaller text supports secondary content.
- Visual hierarchy: clear progression with section labels ("01 - About", "02 - Process", "03 - Work"). Important stats and skill tags are grouped visually.
- Balance: two-column sections balance text with images or supporting content so each area feels stable and legible.
- Contrast: achieved through dark-on-light text, accent highlights for interactive elements, and card backgrounds/borders for separation.

Case Studies notes
- Each project is presented as a contained card with a short description, role, tags, and a single call-to-action. This keeps projects distinct without competing for attention.
